Hai Job 是一款专为求职者打造的智能、隐私优先的 Chrome 浏览器扩展。它能够帮助你直接在浏览器中一键提取、追踪并管理你在各个平台上的职位投递记录。

通过对主流招聘网站的原生数据抓取支持，以及内置的 6 大语言全方位国际化 (i18n) 适配，Hai Job 将成为你求职路上的个人专属 CRM。

## 🌟 核心功能

- **一键智能抓取**：自动从 LinkedIn, Indeed 以及 Jobbank 等主流招聘网站的职位详情页中提取：公司名称、城市、职位信息、工作类型（Remote/Hybrid等）以及当前链接。
- **现代化侧边栏 (Side Panel)**：采用最新的 Chrome Side Panel API，让你在不离开当前网页的情况下，随时调出侧边栏完善并保存投递记录。
- **全功能看板 (Dashboard)**：内置强大的本地管理看板，支持全局模糊搜索以及基于“工作类型”、“面试进度”、“投递平台”的多维度组合筛选。
- **行内状态更新**：可以在看板的表格中直接下拉切换各个职位的“面试进度”，数据实时落盘。
- **CSV 数据双向引擎**：
  - **一键导出**：将所有的求职数据导出为包含 UTF-8 BOM 的标准 CSV 文件，用 Excel 打开绝不乱码。
  - **智能导入**：原生构建的强悍 CSV 解析器。完美支持导入你以前用 Excel 记录的旧数据，内置智能中英文表头映射与严密的“重复记录过滤”逻辑。
- **全球化多语言支持**：原生支持英语、简体中文、繁体中文、日语、韩语和法语。界面文字和动态反馈会根据你的 Chrome 浏览器首选语言无缝切换。
- **绝对隐私安全**：100% 离线运行。所有的求职投递数据均存储在你本地浏览器的 `chrome.storage.local` 中，没有任何数据会被上传至云端服务器。

## 🚀 安装指南 (本地加载)

目前该插件仍在快速迭代中，你可以通过 Chrome 的“开发者模式”在本地进行加载安装。

1. 克隆本项目仓库，并进入 `hai_job` 目录。
2. 打开 Google Chrome 浏览器，在地址栏输入并进入 `chrome://extensions/`。
3. 打开页面右上角的 **开发者模式 (Developer mode)** 开关。
4. 点击左上角的 **加载已解压的扩展程序 (Load unpacked)** 按钮。
5. 选择本地的 `hai_job` 文件夹。
6. 安装成功！建议将 Hai Job 插件固定在浏览器的工具栏上，方便随时点击调用。

## 📖 使用说明

1. **提取职位**：在浏览器中打开任意 LinkedIn, Indeed 或 Jobbank 的职位详情页。
2. **呼出面板**：点击工具栏的 Hai Job 插件图标，屏幕右侧会滑出侧边栏，并自动提取当前页面的核心职位信息填充至表单中。
3. **补充与保存**：你可以根据需要修改提取的信息，补充“面试进度”或“职位来源”，然后点击“保存投递”。
4. **数据看板**：点击面板下方的“查看所有”，即可进入 Dashboard 看板。在这里你可以对所有数据进行搜索、筛选、修改状态、删除以及 CSV 导入/导出。

## 🛠️ 技术栈

- 纯原生 JavaScript (Vanilla JS)
- HTML5 & 纯 CSS3 (无任何第三方 UI 库依赖)
- Chrome Extension Manifest V3 架构
- Chrome Side Panel API & Storage API
